# 輕飛比價 — 機票價格追蹤

一個清爽的機票比價與價格追蹤網站：選好航線與日期，就能直接看到每個航班在各訂票平台的價格，並一鍵前往該網站下訂。

## 網站功能

- **航班搜尋**：來回／單程、出發地與目的地（可一鍵交換）、去回程日期、乘客人數。
- **比價結果**：列出各航空公司航班的時間、飛行時長、直飛或轉機，以及全平台最低價；展開後可比較 Skyscanner、Google 航班、Trip.com、KAYAK、Expedia 的價格差距。
- **前往訂購**：每個平台都有「前往訂購」按鈕，會帶入航線、日期與人數，直接開啟該網站的搜尋結果頁。
- **鄰近日期最低價**：顯示前後幾天的最低票價，標出最便宜的日子，點一下即可切換日期。
- **排序與篩選**：依價格、出發時間、飛行時長排序，可只看直飛。
- **熱門航線**：從台北、高雄、台中出發的熱門目的地最低價一覽。
- **我的追蹤**：把航線加入追蹤，之後再開啟網頁會顯示目前價格與加入時相比的漲跌（資料存在瀏覽器 localStorage）。
- **RWD 響應式設計**：桌機、平板、手機皆可舒適使用。

## 關於價格資料

目前頁面上的價格是**示意資料**，由程式依航線、日期與當天日期計算產生（同一天查詢結果一致，每天會小幅波動），並非真實即時票價。「前往訂購」連結則是真實的平台搜尋頁，實際價格請以該網站為準。

若要改成真實價格，需要串接機票價格 API（例如 Amadeus、Duffel 等），並透過後端伺服器保管 API 金鑰，再把 `getFlights()` 改為呼叫該 API。

## 使用技術

- **HTML5／CSS3**：CSS 變數、Grid／Flexbox、`@media` RWD、`<details>` 展開比價
- **原生 JavaScript**：不需框架或建置工具
- **Google Fonts**：Inter、Noto Sans TC

## 如何開啟

在 Finder 中按兩下 `index.html`，或在終端機執行：

```bash
cd claude-lab
open index.html
```
